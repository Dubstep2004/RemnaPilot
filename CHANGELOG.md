# 📜 История изменений RemnaPilot

> ✨ Новое · 🚀 Улучшено · 🐛 Исправлено · 🛡️ Безопасность · 🔄 Изменено

Последняя версия — [в релизах](https://github.com/Dubstep2004/RemnaPilot/releases/latest). В терминале: `rw --whats-new` и `rw --changelog`.

## v2.2.1

### 🔄 Изменено

- Убраны избранное, скрытые пункты и быстрые клавиши — меню снова простым списком; поиск по слову и компактный режим остались

## v2.2

### ✨ Новое

- Экран «Что нового» после обновления — изменения новой версии по категориям, с цветными значками; вся история — rw --changelog

### 🚀 Улучшено

- История изменений разложена по категориям: новое, улучшено, исправлено, безопасность, изменено — в скрипте, README, CHANGELOG и релизах
- Красивое описание каждого релиза на GitHub: значки, установка, обновление, проверка подлинности, English
- «О программе» показывает изменения последних версий, а не всю историю

### 🐛 Исправлено

- Просмотр длинных списков (логи, журнал) больше не падает без терминала — например, при запуске по SSH без tty

## v2.1

### ✨ Новое

- Удаление RemnaPilot: Прочее → Удалить RemnaPilot или rw --uninstall; панель, ноды и бэкапы остаются
- Меню: избранное наверху, скрытие ненужных пунктов, быстрые клавиши (d, u, c…) и поиск по слову, компактный режим

### 🛡️ Безопасность

- Защита обновлений: каждый релиз с контрольной суммой SHA-256; подменённый файл не установится ни вручную, ни автоматически
- Проверка подлинности: «О программе» и rw --verify показывают, совпадает ли файл с официальным релизом

### 🔄 Изменено

- Лицензия: «Все права защищены» — пользоваться можно, распространять и продавать копии — только с разрешения автора

## v2.0.2

### 🚀 Улучшено

- Если версию определить нельзя — пишется «установлено, версия не определяется», а не «не установлено»

### 🐛 Исправлено

- Панель, подписка и нода показывались «не установлено», когда в образе нет метки версии — теперь версия берётся из тега, package.json или окружения
- Из-за этого автообновление не видело новую версию панели

## v2.0.1

### 🚀 Улучшено

- Журнал cron-задач ограничен 5 МБ

### 🐛 Исправлено

- Задачи cron не видели ufw/sshd/iptables (урезанный PATH)
- Если cron не установлен, расписания молча не работали — теперь ставится сам
- Самообновление перезаписывало работающий файл на месте — теперь через замену файла
- Скрытие подсказок больше не прячет текущие значения в настройках

## v2.0
